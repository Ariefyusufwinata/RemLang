POP vs. OOP in RemLang

Write in the paradigm that best solves your architecture.

examples/procedural.rem 
promise beloved = "Subaru-kun"
promise max_retries = 3

dream calculate_score(scores) {
    remember total = 0
    again each s in scores {
        total = total + s
    }
    wake_with total
}

rem_wakes_up {
    remember memories scores = [10, 20, 30]
    add(scores, 40)
    sleep_talk "Total scores: " + calculate_score(scores)
    sleep_talk "Item count: " + count(scores)

    remember attempt = 0
    again while attempt < max_retries {
        attempt = attempt + 1
        maybe attempt == 2 {
            turn_over
        }
        sleep_talk "Executing trial #" + attempt
    }
}
goodnight
examples/oop.rem 
class OniMaid {
    dream init(name, role, mana) {
        this.name = name
        this.role = role
        this.mana = mana
        this.horn_active = no
    }

    dream activate_horn() {
        this.horn_active = yes
        this.mana = this.mana + 50
        sleep_talk this.name + " sprouted glowing Oni horn! Mana: " + this.mana
    }

    dream cast_spell(spell, cost) {
        maybe this.mana < cost {
            die this.name + " lacks mana for " + spell + "!"
        }
        this.mana = this.mana - cost
        sleep_talk this.name + " cast [" + spell + "]! Remaining: " + this.mana
    }
}

rem_wakes_up {
    remember rem = new OniMaid("Rem", "Head Maid", 100)
    rem.activate_horn()
    rem.cast_spell("Al Huma", 30)
}
goodnight
tests/return_by_death.rem 
rem_wakes_up {
    sleep_talk "Approaching dangerous timeline..."

    save_point {
        remember risky_operation = 10 / 0
    } return_by_death {
        sleep_talk "Fatal error caught! Returning by Death to checkpoint!"
        sleep_talk "Timeline restored safely, Subaru-kun."
    }
}
goodnight

Getting Started

Zero dependencies. Installs in seconds on macOS, Linux, and Windows.

macOS & Linux

Run the official one-liner in your terminal:

curl -fsSL https://raw.githubusercontent.com/Ariefyusufwinata/RemLang/main/install.sh | bash

Manual Build

Clone the repository and run the build script:

git clone https://github.com/Ariefyusufwinata/RemLang.git
cd RemLang
./build.sh

Windows Native

Run the native Windows command batch file:

git clone https://github.com/Ariefyusufwinata/RemLang.git
cd RemLang
build.bat
